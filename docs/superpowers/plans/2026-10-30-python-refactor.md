# 实施计划

依据已确认的 Python + Tkinter 方案推进，无第三方运行依赖。

1. 建立 Python 包、标准库文件/日志/DPAPI/配置模块；添加针对兼容格式的回归测试。
2. 实现供应商档案、目录与事务切换，部署独立 Python 凭证助手。
3. 移植 JSONL 运行时与兼容转换、SQLite 备份恢复、fork 和投影缓存处理。
4. 实现共享 CLI、中文 Tkinter GUI、异步任务和监测窗口。
5. 将旧实现归档，更新双击入口与文档，运行完整回归、旧引擎对照、性能及 GUI 冒烟验证。
6. 审核功能覆盖、运行依赖与 git diff，提交完整可用版本。
