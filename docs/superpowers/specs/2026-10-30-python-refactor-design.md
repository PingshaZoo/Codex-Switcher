## 模块边界

- config：仅替换工具托管的模型根键和标记区，保留其它配置文本；使用 tomllib 校验最终 TOML。无法安全局部编辑的多行托管值在写入前拒绝。
- credentials：ctypes 调用 Windows DPAPI，兼容 PowerShell ConvertFrom-SecureString 的十六进制密文及 UTF-16LE 明文；凭证命令独立部署到配置旁，不依赖工作区位置。
- profiles / catalogs：兼容 providers.json v1、旧 state.json + deepseek.key、旧别名与已有能力目录；密钥留空沿用，ID 保存后固定；未知供应商不套用 DeepSeek 能力模板。
- storage / platform：UTF-8 无 BOM + LF、原子替换、文件备份与恢复、SQLite 一致性备份、进程检查、互斥切换、脱敏诊断日志。
- migration：JSONL 逐行流式改写和 SQLite 索引更新；保留 ID、可见消息、服务器响应 ID、创建时 provenance；转换隐藏推理与工具 ID；修复 fork 字节偏移；清空可重建的投影缓存。
- monitor：默认配置与会话运行时分开呈现，支持尾部扫描、完整时间线、全部会话扫描、暂停和日志。响应 ID 只表明格式特征，不声称验证后端身份。
- gui / cli：共享业务模块；GUI 工作线程执行耗时任务，主线程处理控件；进度与异常通过队列回传。

## 切换与恢复

先校验输入、配置和目录，再检查 Codex/ChatGPT 是否退出，取得工具互斥锁，保存备份清单。配置、档案、密文、凭证助手、目录和可选会话迁移属于同一次操作。提交配置前再次检查进程和文件是否被外部修改。失败时恢复同批文件、数据库和会话，报告恢复失败及备份位置。

默认不读写历史数据库或 rollout。勾选迁移后处理 sessions 与 archived_sessions，以及根目录/sqlite 下最新有效 state 和投影数据库。损坏文件保持原字节并报告，同时还原其索引路由；全部可处理文件均失败时整体回滚。fork 按依赖顺序修复，缺失父会话或循环依赖导致整体回滚。

官方根配置可为空，不迁移历史时无需猜测官方模型。迁移时按保存配置、保存的官方模型、明确填写的 gpt-* 名称、本机官方模型证据确定目标；没有目标时在写入前失败。auth.json、MCP、skills、插件、信任设置不变。
