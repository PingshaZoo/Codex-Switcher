Codex 多供应商切换 · Python 版
=============================

环境：Windows + Python 3.11 或更高版本（含 Tkinter），无需 pip 安装第三方库。
双击 Start.cmd 打开中文界面；详细用法、备份恢复和测试命令见 README.md。

1. 先正常退出 Codex / ChatGPT 桌面应用和 Codex 命令行。
2. 确认生效的 config.toml。默认使用 CODEX_HOME，否则使用当前用户的 .codex。
3. 首次使用应从已登录官方账号的配置开始，以保存官方模型设置。
4. 点击“新增”，填写供应商 ID、名称、HTTPS 接口、API Key 和模型列表。
5. “保存修改”只保存档案；“切换到所选供应商”才会应用配置。
6. 密钥留空沿用原密钥；填写新密钥则更新。已保存 ID 固定，名称和其它字段可修改。
7. 可选模型目录必须是对应供应商提供的完整能力目录 JSON，不会套用其它供应商模板。
8. 默认不迁移历史。只有勾选“同时迁移全部历史会话”才会改写旧会话和数据库。
9. 成功后重新打开 Codex。切回官方使用“切换到官方登录”。

密钥继续用 Windows 当前用户 DPAPI 加密，兼容旧 PowerShell 版本的档案和密文。
运行时已完全改为 Python，不再依赖 PowerShell、C# 编译或第三方 SQLite DLL。
Python 解释器必须保留在切换时的位置，Codex 会通过该解释器调用配置旁的独立凭证助手。
更换 Python 安装路径后，重新运行本工具并应用一次配置。

双击“检查当前对话.cmd”只读查看最近会话；支持 -ScanAll 参数查看全部会话。
图形监测支持每 3 秒刷新、暂停、完整时间线、日志。
响应 ID 仅能分类格式，不能单独证明后端身份；当前配置也不能证明历史请求去向。

每次应用前的备份：config.toml 同目录 codex-switcher/profile-backups/。
运行日志：codex-switcher/runtime.log，启动失败日志：%LOCALAPPDATA%/Codex-Switcher/logs/runtime.log。
失败时会尝试恢复同批配置、档案、密钥、目录和会话；若恢复失败，错误会显示备份路径。
备份可能含 MCP 凭证和完整对话，勿公开分享。

原 PowerShell / C# 版本和测试已归档到 legacy/，不参与新版运行。
